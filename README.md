One line, 121 characters: the dog's own excuse for eating the homework — it crinkled exactly like a treat bag, and no dog has ever once been rewarded for double-checking. The program writes the line to /output/entry.txt, byte for byte the same on every run, and refuses to write anything outside the gate (one line, 1 to 200 characters).

## Run it

```sh
node main.ts
```
